# Zoo das Letras

App de alfabetização para celular com a hamster Pipoca: histórias narradas em que a criança completa as palavras para salvar os bichos, treino livre com letras e sílabas, e um zoológico de figurinhas.

## Como abrir
Abra o link do GitHub Pages no celular e use "Adicionar à tela inicial". Depois disso ele abre como um app e funciona sem internet.

## Arquivos
- `index.html` — o app inteiro, com as falas da narração embutidas.
- `sw.js` e `manifest.webmanifest` — permitem instalar na tela inicial e usar offline.
- `audio/` — as falas separadas (`c1-01.mp3`…) e o script `split.py` que as corta a partir dos áudios do ElevenLabs.
- `roteiro-elevenlabs.txt` — o texto de cada fala.

## Voz
Bea, do ElevenLabs (modelo Multilingual v2).

## Progresso
Estrelas, bichinhos e estatísticas ficam salvos no próprio celular, em cada aparelho separadamente.
